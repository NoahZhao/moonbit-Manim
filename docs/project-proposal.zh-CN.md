# MoonManim 项目申报书

## 1、项目名称

**MoonManim——用 MoonBit 制作可交互数学课程**

## 2、项目简介

数学课里有一类内容，单靠静态图片很难讲清楚：割线怎样变成切线，矩阵怎样改变空间，曲线是怎样被画出来的，卷积窗口为什么会得到某个特征值。教师通常需要分别准备动画、网页演示和课堂讲解，修改一次内容就要同步维护多份材料。

MoonManim 是一个用 MoonBit 编写的数学动画与交互课程引擎。它把几何对象、公式、参数和时间线放在同一个场景模型中，再从这份模型生成浏览器交互、逐帧 SVG 和离线视频。学生可以观看课程，也可以在暂停的位置接管参数，继续探索数学关系；作者只需要维护一份场景代码。

项目目前已经完成二维几何、函数绘图、贝塞尔路径、公式动画、动态依赖和参数化课程的核心实现，并提供了割线与切线、矩阵变换、勾股定理、黎曼和、贝塞尔曲线、利萨如曲线和 CNN 过程演示等案例。

## 3、项目要解决的问题

现有数学动画工具通常擅长把场景渲染成视频，但“讲解”和“练习”往往是两套内容：视频里的某个时刻无法直接变成可操作的模型，网页里的交互逻辑也常常需要重新实现。这样会带来三个问题：

1. 内容重复制作，视频和网页修改后容易出现不一致；
2. 公式和几何图形在渲染后只剩像素，难以表达“哪个符号对应哪个符号”；
3. 动画过程缺少可检查的状态，难以验证不同输出端是否展示了同一个数学过程。

MoonManim 的目标不是再做一个通用视频编辑器，而是为数学教学提供一套可以运行、暂停、修改和复现的课程模型。

## 4、已完成的功能与案例

### 4.1 数学对象与动画

- 三次贝塞尔路径、轮廓、弧长测量和部分路径；
- 坐标平面、函数采样、矩阵与仿射变换；
- Create、Write、Transform、Fade、Rotate、Shift、错峰和并行动画；
- `ValueTracker` 与 `Updater`，用于驱动动点、切线、辅助线和参数标签；
- 公式资产从 TeX 转换为矢量路径，公式片段保留稳定的语义 key，可以独立移动、变色和转场。

### 4.2 课程与交互

割线与切线是目前最完整的课程案例。课程包含六个章节，章节目标、参数范围、动画时间和字幕由 MoonBit 定义。浏览器播放到任意时刻后，用户可以暂停讲解，修改 `x` 和 `h`，观察割线斜率变化，再返回原来的课程时间线。

这不是把视频旁边放一个独立的滑块，而是让视频和交互使用同一套参数采样逻辑。原生适配器与浏览器 JavaScript 会在多个检查点比较章节、参数和 SVG 坐标，确认两端展示的是同一个场景状态。

### 4.3 输出与运行环境

- `native`：运行场景、生成 SVG 和离线帧流；
- `JavaScript`、`wasm`、`wasm-gc`：在浏览器中实时生成交互帧；
- SVG：用于网页预览、逐帧检查和静态发布；
- Node.js、sharp 与 FFmpeg：把 MoonBit 生成的帧流编码为视频，并处理字幕和旁白资产。

在线展示站是静态 GitHub Pages，不需要安装 MoonBit 或登录即可体验：

- [在线展示站](https://noahzhao.github.io/moonbit-Manim/)；
- [割线与切线课程](https://noahzhao.github.io/moonbit-Manim/?scene=tangent#playground)；
- [能力矩阵](https://noahzhao.github.io/moonbit-Manim/features.html)；

## 5、与 Motiva 的关系

MoonManim 与 [Motiva 0.3.0](https://mooncakes.io/docs/CAIMEOX/Motiva@0.3.0) 都受 Manim 启发，也都使用 MoonBit 实现场景、动画和几何，因此在基础能力上有交集。两者不是同一个项目，MoonManim 也不依赖或复制 Motiva 的代码。完整对比见[《MoonManim 与 Motiva：生态位和功能关系说明》](moonmanim-motiva-positioning.zh-CN.md)。

根据 Motiva 0.3.0 的公开文档，Motiva 主要沿 **Native 优先的通用动画与影片制作** 路线发展，提供 Cairo 二维/三维渲染、SVG/TeX/Pango 文字、音频、章节、影片缓存和 FFmpeg 生产流程。它解决的是开发者如何在本地制作一部完整影片，但公开模块只支持 Native，运行还依赖本地 C/Cairo/Pango/FFmpeg 等环境，学生和普通教师很难直接打开使用。

MoonManim 选择的是另一条路线：**面向数字教材和科学教学的跨端课程引擎**。它解决的是学习者如何理解一个变化过程，已经把“观看—暂停—探索—返回”做成课程闭环：

| 对比维度 | Motiva | MoonManim |
| --- | --- | --- |
| 主要场景 | 本地制作通用动画和影片 | 制作数学课程、算法演示和交互实验 |
| 运行重点 | Native | Native 与 Web/Wasm 同时考虑 |
| 核心产物 | 影片、图像和媒体时间线 | 视频、浏览器实验和可检查的数学状态 |
| 课程体验 | 播放和导出影片 | 播放、暂停、接管参数、探索后回到课程 |
| 数学表达 | 通用对象、文字和公式 | 语义公式项、几何依赖、章节目标和参数轨道 |

Motiva 的功能数量并不等于教育价值：三维、音频和影片缓存可以帮助作者交付成片，却不能自动让学生理解中间过程，也不能替教师建立可复用的交互课程。MoonManim 的优势在于浏览器可直接访问、视频可接管探索、课程可跨端核验，面向的是更广泛的学习者和教育平台。两者可以共存，但在数字教材和科学传播这个生态位上，MoonManim 更接近最终用户真正需要的产品。

## 6、项目创新点

### 6.1 一份课程同时服务视频和交互

课程的参数、章节、目标状态和时间边界由同一份 MoonBit 场景描述。浏览器使用它实时生成 SVG，视频导出器使用它逐帧求值，修改课程时不需要分别维护两套运动逻辑。这是 MoonManim 与普通“视频加网页演示”方案的主要区别。

### 6.2 数学对象保留语义身份

公式不是一张不可拆分的图片，几何也不是已经烘焙好的像素。公式片段、路径轮廓、控制点和对象 ID 都保留在场景模型中，因此可以表达“这个符号变成了哪个符号”“这条曲线的哪一段正在被描绘”等教学关系。

### 6.3 输出结果可以复现和检查

动画时间由确定性的帧时钟推进，Updater 依赖按固定顺序计算，渲染器接收冻结的帧状态。项目可以比较原生和浏览器输出的章节、参数及 SVG 坐标，也可以对视频帧数、尺寸和编码结束状态进行检查。这使动画不仅能播放，也能作为可验证的计算过程使用。

### 6.4 以 MoonBit 为第一语言

项目没有建立 Python API 兼容层，而是用 MoonBit 重新设计数学对象、场景、动画和输出接口。这样可以利用 MoonBit 的静态类型和多编译目标，把同一套核心逻辑带到原生程序和 Web 环境中，也为 MoonBit 生态提供一个真实的图形与教学应用案例。

## 7、预期使用场景

- **课堂讲解：** 教师播放割线趋近切线的过程，暂停后让学生改变两点间距，观察斜率如何变化。
- **课程与教材制作：** 作者用一份场景代码同时生成讲解视频和配套交互页，减少重复维护。
- **算法与技术培训：** 用逐帧场景展示卷积、池化、坐标变换等过程，让学习者看到中间状态，而不只是最终结果。
- **教育平台接入：** 平台根据题目参数调用同一个课程模型，生成可嵌入的函数图像、几何证明或算法演示。
- **科学可视化：** 研究人员用可复现的参数和时间线制作报告中的动态解释，并导出静态 SVG 或视频。

## 8、后续计划与项目边界

接下来优先完善教学内容生产链，而不是盲目追求与大型通用动画框架的功能数量：

1. 完善数学语义场景图，把公式项、几何对象和讲解意图建立可查询的关系；
2. 稳定 Scene IR 和增量求值，为大型交互场景和可视化编辑器打基础；
3. 完善课程模板、旁白和字幕时间线，降低教师制作一套课程的成本；
4. 增加移动相机、动态数值标签和更完整的公式布局；
5. 根据实际教学案例评估三维和 GPU 后端的优先级。

当前项目的边界也会如实保留：尚未提供完整 Manim/ManimGL 兼容层、运行时 TeX 编译、通用 SVG 导入、完整 Mesh/GPU 三维后端或引擎内媒体编码。视频导出目前由 Node.js/sharp 与 FFmpeg 适配器完成，TeX 公式资产主要在构建阶段生成。这些限制不影响当前二维数学课程和浏览器交互案例，但会在后续版本中单独验证。

## 9、项目性质、参考资料与许可证

MoonManim 是一个参考已有开源思想、独立实现的 MoonBit 项目。项目借鉴 Manim 的程序化动画理念，但没有追求 Python 源码兼容；数学模型、几何算法、场景运行、课程时间线和浏览器桥接均由本项目实现。

主要参考资料：

- [MoonBit 官方文档](https://docs.moonbitlang.cn/)；
- [Manim Community Edition](https://github.com/ManimCommunity/manim)；
- [cai-hust/manim-tutorial-CN](https://github.com/cai-hust/manim-tutorial-CN)；
- [Motiva 0.3.0 文档](https://mooncakes.io/docs/CAIMEOX/Motiva@0.3.0)，用于功能和生态位对照。

## 10、复现与验收

项目提供以下检查入口，评审可以据此核验申报中的主要能力：

```sh
moon check --target all --deny-warn
moon test --target all --deny-warn
make check
make test
npm run site:check
npm run lesson:check
```

其中 `lesson:check` 会比较原生课程适配器和已编译浏览器引擎在多个时间点的章节、参数和 SVG 数值坐标；在线展示站提供无需本地构建的交互结果。
