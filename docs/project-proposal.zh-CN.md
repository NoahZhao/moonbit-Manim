# MoonManim 项目申报书

**1、项目名称**  
MoonManim——基于 MoonBit 的数学动画与交互演示引擎

**2、项目简介**  
数学教学中的许多难点，需要把变化过程展示出来才能讲清楚。MoonManim 希望让教师和内容创作者通过代码描述图形、公式及其变化，制作可以反复修改和使用的教学内容。目前，项目已用 MoonBit 实现二维几何、函数绘图、公式动画和参数交互，并完成割线趋近切线等教学案例。同一份课程既能导出视频，也能生成供学生动手操作的网页。项目的价值在于减少重复制作，让一份优质讲解能够用于课堂、在线课程和数字教材。

**3、项目方向及通用性**  
项目面向数字教育与科学可视化，核心支持本地、JavaScript 和 WebAssembly 等编译目标。绘图、动画和课程编排能力可以复用到物理演示、算法讲解及工程培训中。数字教材和在线课程对动态、可交互内容的需求，为项目提供了实际应用空间。后续计划以开源引擎吸引开发者和教师使用，围绕课程模板、教育平台接入、云端渲染和定制开发开展专业服务。

**4、预期使用场景**

- **课堂讲解：**教师讲授导数时，播放割线逐渐趋近切线的过程；学生暂停动画、改变两点间距，观察斜率变化，再返回讲解进度，把公式与图形联系起来。
- **课程与教材制作：**课程团队编写勾股定理或矩阵变换的讲解脚本，同时输出视频和配套交互页面。修订内容时修改同一份脚本，减少多个版本分别维护的工作。
- **科研与技术培训：**研究人员或企业讲师将算法步骤、坐标变换等过程制作成动画，用于报告、技术文档或培训课程，帮助受众理解静态图表难以呈现的变化关系。
- **教育平台接入：**平台开发者将引擎嵌入课程或题目页面，根据不同题目的参数生成函数图像和演示过程，使同一个讲解模板能够服务一类问题。

**5、拟实现的核心功能**  
在已有二维引擎基础上，完善几何绘图、公式变换、对象联动和交互控制；统一课程的视频与网页输出，支持旁白、字幕和动画同步；提供常用教学模板、批量导出工具及平台调用接口。优先把备课、制作和发布流程做完整，再逐步扩展三维场景与 GPU 渲染。

**6、项目性质与创新点**  
项目属于**参考已有开源项目的自主重实现**，借鉴 Manim 的程序化动画设计，核心数学、几何、场景和动画逻辑由 MoonBit 编写。重点探索同一份课程在视频讲解与交互操作之间的复用，同时为国产语言 MoonBit 积累可用于实际教学和内容制作的图形工具。
