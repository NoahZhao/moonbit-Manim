# MoonManim 项目申报精华版

**1、项目名称**  MoonManim——让数学过程成为可探索的课程

**2、项目简介**  数学教育最重要的难题，不是学生记不住结论，而是看不见结论如何发生。MoonManim 用 MoonBit 把图形、公式和变化过程做成可观看、可暂停、可操作、可复用的课程。学生可以在视频暂停处改变参数，亲自观察规律，再回到讲解。项目已有导数、矩阵、勾股定理、黎曼和、贝塞尔曲线、CNN 等案例和公开展示站。

**3、项目方向与通用性**  面向数字教材、在线课程和科学传播，也可用于物理、算法、工程培训和科研报告。一份课程同时生成视频和交互实验，教师、学生和平台不再维护两套内容；数学关系可以被保留、检查和复用，适合长期积累开放课程资源。

**4、预期使用场景**

- **导数课堂：**暂停割线趋近切线的过程，调整点和间距，观察极限出现。
- **数字教材：**把勾股定理或矩阵证明同时发布为视频与互动页面。
- **算法培训：**逐步展示卷积、ReLU、池化，学习者检查每个中间结果。
- **科学传播：**将函数、几何和算法过程嵌入报告、课程与公共科普内容。

**5、拟实现的核心功能**  面向课程作者提供数学对象、公式、动态参数、章节编排、视频发布和互动探索；继续完善课程模板、字幕旁白、内容复用和教育平台接入，形成从数学想法到公开课程的完整工具链。

**6、项目性质、参考项目与许可证**  MoonManim 是原创项目，不是移植项目，未采用 Motiva 代码。参考 [Manim Community Edition](https://github.com/ManimCommunity/manim) 的程序化动画理念（MIT License），以 MoonBit 独立实现课程体验。MoonManim 原创代码采用 MIT License，公式资产许可见仓库说明。

**7、与 Motiva 的关系及价值**  [Motiva 0.3.0](https://mooncakes.io/docs/CAIMEOX/Motiva@0.3.0) 先探索了 MoonBit 原生动画与影片制作（Apache-2.0），主要服务本地开发者制作影片，公开模块只支持 Native，还要求 C/Cairo/Pango/FFmpeg 等环境。MoonManim 进一步回答“学习者如何理解变化”：把影片变成能看、能停、能改、能验证、能继续探索的课程。Motiva 更像工程师的内容生产库，MoonManim 面向教师、学生和教育平台；二者有基础重叠，但 MoonManim 更直接解决数字教材和知识传播问题，具有更大的公共价值。项目已完成“观看—暂停—探索—返回”闭环，把一次性动画变成可学习、可复用、可传播的数学课程。
